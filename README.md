# Workout PWA — shell

Minimal installable PWA shell for iOS. Open in Safari on your iPhone, then
**Share → Add to Home Screen**.

## Run locally

A service worker requires `https://` *or* `http://localhost`. Plain HTTP from
your laptop's LAN IP will not register the SW (and iOS will not treat it as
installable).

### Option A — quick LAN test (no install)

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Visit `http://<your-laptop-ip>:8000` from the iPhone. The page renders, but
the service worker stays unregistered and *Add to Home Screen* may not behave
like a real PWA.

### Option B — HTTPS over LAN (recommended for iPhone install test)

Use a tunnel that gives you an HTTPS URL:

```sh
# from this directory
python3 -m http.server 8000
# in another terminal
npx --yes localtunnel --port 8000
# or: cloudflared tunnel --url http://localhost:8000
```

Open the HTTPS URL in Safari on the iPhone, then **Share → Add to Home
Screen**. Launch from the home screen — `Standalone: yes` should show in the
diagnostics card.

## Layout

- `index.html`, `styles.css`, `app.js` — the shell
- `manifest.webmanifest` — PWA manifest
- `service-worker.js` — caches the shell for offline launch
- `icons/` — generated by `scripts/make_icons.py`

To regenerate icons: `python3 scripts/make_icons.py`.
