# Workout PWA

An installable iOS PWA for tracking strength training around **ranges**, not
fixed prescriptions.

## The idea

Most apps tell you to do *3 x 8 at 135 lb*. In practice you walk up to the bar
and feel like 145 today, or you knock out 10 instead of 8. The number on the
plan stops matching reality, so you stop following it.

This app instead lets you set, per exercise:

- a **rep range** (e.g. 6–10)
- a **weight range** (e.g. 135–185 lb)

You log whatever you actually did. The app only nudges you to **upgrade the
range** once you're consistently working at the top of it — push the floor and
ceiling up together and keep moving.

## Run locally

A service worker requires `https://` *or* `http://localhost`. Plain HTTP from
your laptop's LAN IP will not register the SW (and iOS will not treat it as
installable).

### Option A — quick LAN test (no install)

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Visit `http://<your-laptop-ip>:8000` from the iPhone. The page renders, but
the service worker stays unregistered and *Add to Home Screen* may not behave
like a real PWA.

### Option B — HTTPS over LAN (recommended for iPhone install test)

Use a tunnel that gives you an HTTPS URL:

```sh
# from this directory
python3 -m http.server 8000
# in another terminal
npx --yes localtunnel --port 8000
# or: cloudflared tunnel --url http://localhost:8000
```

Open the HTTPS URL in Safari on the iPhone, then **Share → Add to Home
Screen**. Launch from the home screen and the app should run standalone.

## Layout

- `index.html`, `styles.css`, `app.js` — the shell
- `manifest.webmanifest` — PWA manifest
- `service-worker.js` — caches the shell for offline launch
- `icons/` — generated by `scripts/make_icons.py`

To regenerate icons: `python3 scripts/make_icons.py`.
